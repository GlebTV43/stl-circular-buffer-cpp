# Circular Buffer — STL-совместимый кольцевой буфер

Контейнер `circular_buffer<T, Extendable, Alloc>` с кольцевым размещением элементов, поддержкой пользовательского аллокатора и выбором поведения при заполнении.

Лабораторная работа №6 по C++ в ИТМО.

## Возможности

- Добавление и удаление с обоих концов, вставка и удаление элементов.
- Фиксированная ёмкость или автоматическое расширение.
- Обычные, константные и обратные итераторы.
- Поддержка аллокаторов и типов без конструктора по умолчанию.
- Тесты исключений, правил копирования/перемещения и нестандартных аллокаторов.

## Что изучено и применено

- Шаблоны классов и требования к STL-контейнерам.
- Итераторы произвольного доступа и совместимость с алгоритмами.
- Аллокаторы, время жизни объектов и ручное управление памятью.
- Конструкторы, присваивание, копирование и перемещение.
- GoogleTest, проверка именованных требований и покрытие кода.
- Гарантии исключений, время жизни элементов и поведение allocator_traits при копировании и перемещении.

## Сборка

Требуются компилятор с поддержкой C++23 и CMake 3.12 или новее. Команды выполняются из корня репозитория. При первой настройке CMake загружает тестовые или сетевые зависимости, поэтому нужен интернет.

```sh
cmake -S . -B build -DRUN_EXT_TESTS=ON
cmake --build build --parallel
```

В Visual Studio и других генераторах с несколькими конфигурациями добавьте `--config Debug` к команде сборки. Исполняемые файлы в таком случае могут находиться в подкаталоге `Debug`.

## Тесты

В проекте есть тесты GoogleTest.

```sh
cmake --build build --target circular-buffer-lib-tests
ctest --test-dir build --output-on-failure
```

Для генераторов с несколькими конфигурациями используйте `--config Debug` при сборке и `-C Debug` при запуске CTest.
